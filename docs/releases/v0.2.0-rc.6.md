# v0.2.0-rc.6 — current-only Production candidate

`v0.2.0-rc.6` is a Slice 3 release candidate. It retains the validated RC.5 Power behavior and adds the current-only Production vertical. It is not final `v0.2.0`, does not start Map work, and must not be treated as Unraid-validated until the candidate image is tested against the authorized live deployment.

## Delta from RC.5

- Retains the shared runtime/reliability foundation: explicit source states and provenance, request IDs, structured redacted logs, privacy flags, and bounded retries for the existing Overview and Power adapters.
- Adds a pinned-source FRM `getProdStats` adapter with strict upstream parsing and a normalized application-owned production model.
- Adds bounded normalized item search/detail through `/api/v1/production` and `/production`.
- Publishes current production, consumption, net rate, theoretical capacity, and efficiency where the source supports them.
- Returns valid empty results and explicit unavailable states without conflating them.
- Returns `{state:"unsupported",reason:"production-history-not-observed"}` for Production history. No PostgreSQL, Prometheus production series, Grafana, or fabricated history is included.
- Adds Production API assertions to the authoritative container smoke gate and responsive desktop/mobile browser evidence.
- Adds a bounded, server/query-keyed 5-second Production promise cache shared by API and page reads, plus the established default-server fallback for stale bookmarks.

## Power preservation and live cadence

The candidate preserves RC.5 Power behavior: 15m/5s history, approximately 181 rolling points, browser-visible approximately 5-second refresh, source-aware history cache expiry, realtime Power SSE, major-consumer filtering, source-fidelity validation, the 2,000-point bound, 15-day retention behavior, and public privacy/security contracts.

The operator-validated Unraid Power profile uses:

```yaml
global:
  scrape_interval: 5s
  evaluation_interval: 10s
```

with `PROMETHEUS_SCRAPE_INTERVAL_SECONDS=5`, `storage.tsdb.retention.time=15d`, and `storage.tsdb.retention.size=0B`. The repository-safe application default remains `15` for mock mode, generic deployments, and rollback outside that verified profile. The pinned monitoring source snapshot still records its own immutable 15-second configuration; that source evidence is not a claim about the selected live deployment.

## Deployment delta

- Image: `ghcr.io/sorilo/satisfactory-control-center:v0.2.0-rc.6`, preferably pinned to the full merged-main SHA or manifest digest.
- Recreate only the Control Center service.
- No new environment variables, networks, secrets, volumes, database migrations, upstream write access, or public upstream exposure.
- `POWER_STREAM_ENABLED` remains `false` unless the existing public proxy/Tunnel SSE gate is separately validated.
- Production history remains unsupported and must stay visible as such.
