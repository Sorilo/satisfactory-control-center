# v0.2.0-rc.2 — Slice 2 Power polish candidate

`v0.2.0-rc.2` is the direct-LAN validation candidate for the approved Slice 2 Power polish pass. It is intentionally not final `v0.2.0` and does not begin Slice 3.

## Delta from RC.1

- Reusable dependency-free telemetry history chart with mouse hover/drag, touch tap/horizontal drag, keyboard inspection, crosshair, selected markers, bounded all-series tooltip, and accessible value text.
- Exact timestamp intersections for derived headroom/utilization while raw telemetry retains nearest-sample inspection.
- Pixel-bounded render-path downsampling with full retained data available for inspection.
- Current capacity, consumption, maximum demand, headroom, utilization, fuse state, and circuits update in place from accepted `power` SSE events.
- Additive `power-details` SSE events carry changed generator and major-consumer snapshots on a slower 30-second shared server-owned cadence.
- Detail production has independent degradation, per-channel one-frame coalescing, bounded frames, abortable exponential recovery backoff, and no browser-to-FRM polling.
- Existing battery empty/full estimates render as human-readable durations; the validated no-capacity sentinel maps to no battery.
- Malformed detail events do not close a healthy current-Power stream.

## Preserved boundaries

- `POWER_STREAM_ENABLED=false` remains the safe default.
- HTTP polling fallback, connection limits, same-origin transport, independent Prometheus history, and private upstream boundaries are preserved.
- No raw IDs, class names, locations, orientations, internal URLs, or unresolved production fields are public.
- `PowerProduction` remains omitted.
- Battery capacity and separate input/output remain omitted until nonzero live evidence verifies their units.
- No PostgreSQL persistence, map/location contract, final `v0.2.0`, or Slice 3 work is included.

## Direct-LAN validation

Follow [`../deployment-unraid.md`](../deployment-unraid.md). Establish the ordinary HTTP baseline first, set `POWER_STREAM_ENABLED=true`, recreate only Control Center, then validate the stream and physical browser behavior directly on the LAN.

Require:

- initial and changed `event: power` frames;
- changed `event: power-details` frames when generator/consumer state changes;
- heartbeat comments and prompt disconnect cleanup;
- in-place current telemetry and circuit changes without page reload;
- HTTP polling fallback after bounded stream failures;
- mouse, touch-drag, keyboard, tooltip containment, and no page-level horizontal overflow;
- no raw IDs, class names, locations, orientations, internal endpoints, or unresolved production fields.

Direct-LAN success does not validate Cloudflare Tunnel or reverse-proxy buffering. Keep public-path SSE unvalidated until that exact path is exercised.

## Rollback to RC.1

Set the external image reference to:

```text
ghcr.io/sorilo/satisfactory-control-center:v0.2.0-rc.1
```

Set `POWER_STREAM_ENABLED=false`, recreate only Control Center, and verify health plus the ordinary Overview and Power HTTP contracts. RC.2 adds no database migration or persistent application volume, so rollback requires no data migration.
