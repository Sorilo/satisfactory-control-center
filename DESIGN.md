# Design tokens

## Color

- Canvas `#0d1016`; surfaces `#141922`, `#1b222e`, `#232c3a`.
- Primary text `#e7ecf3`; secondary `#aeb9c8`; muted `#8492a6`.
- Accent `#ff8a3d`; accent strong `#ffa76b`.
- Success `#34d399`; warning `#fbbf24`; danger `#f87171`; info `#60a5fa`.

## Type and geometry

Use system sans-serif for UI and system monospace with tabular numerals for telemetry. Base spacing is 4px. Controls use 4px radius; panels use 8px. Elevation is border/surface contrast rather than large shadows.

## Component language

Panels have compact uppercase eyebrow labels, strong numeric hierarchy, a visible freshness/state treatment, and restrained corner accents. Navigation is a desktop rail and mobile scrollable top-level strip/drawer. Charts and maps must have accessible textual summaries.
